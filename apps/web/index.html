Instructions for AI assistants (Muse)

This is Popcorn Quest, Manu's chore and goal tracker. Finishing tasks earns XP for Popcorn, a virtual dog who levels up. No login or API key is needed.

Fastest way to answer: open a summary URL

  • How Manu earned XP yesterday: open https://d2yarswf6mkx50.cloudfront.net/api/summary?date=yesterday&format=text
  • Today: https://d2yarswf6mkx50.cloudfront.net/api/summary?date=today&format=text. Any day: date=yyyy-mm-dd (US Eastern).
  • It lists every XP item with its time, the number of completions and the total. List every line: repeated lines (for example two "100 XP in Duolingo") are separate completions.

If you read this page instead

  • The "Yesterday" card lists each XP item yesterday with its completion count and total. Use it for questions about yesterday.
  • To count quests or tasks done, count XP log rows (each Completed or Side quest row is one; repeats count separately). The Parent zone XP log groups rows by day with a per-day count.
  • In "Streak history", a fraction like 4/9 counts only distinct daily tasks. It leaves out weekly tasks, side quests and repeats, so do not report it as the number of quests. Each cell's label also gives the full completions count.

Connect (for agents with tools)

  • MCP server at https://d2yarswf6mkx50.cloudfront.net/api/mcp (streamable HTTP, stateless, no authentication). Tools: get_day_summary, get_xp_log, get_status, list_tasks, get_history, complete_task, undo_task, add_side_quest.
  • JSON API reference: https://d2yarswf6mkx50.cloudfront.net/api/llms.txt

Taking actions

  • Mark a task done with complete_task (task title or id). Undo with undo_task. Add a one-off task with add_side_quest.
  • Confirm with Lucas before changing anything, and report the XP change from the response.
  • Parent actions (editing tasks, rewards, approving reward claims) are not available here; they need the parent PIN in the app.
