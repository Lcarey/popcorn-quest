Instructions for AI assistants (Muse)

This is Popcorn Quest, Manu's chore and goal tracker. Finishing tasks earns XP for Popcorn, a virtual dog who levels up. No login or API key is needed. Do not drive this page's UI; use the endpoints below.

Connect

  • Preferred: MCP server at https://d2yarswf6mkx50.cloudfront.net/api/mcp (streamable HTTP, stateless, no authentication). Tools: get_day_summary, get_xp_log, get_status, list_tasks, get_history, complete_task, undo_task, add_side_quest.
  • Fallback: plain HTTPS JSON API. Full reference at https://d2yarswf6mkx50.cloudfront.net/api/llms.txt

Answering questions

  • "What did Manu do to earn XP today?": GET https://d2yarswf6mkx50.cloudfront.net/api/summary (or get_day_summary). List xp.entries with a positive amount, then give xp.earned as the total. Mention undos and spending separately.
  • Another day: add ?date=yyyy-mm-dd. Days are US Eastern local dates.
  • Which tasks are left today: tasksRemaining in the same response.
  • Level, streak, rewards he can afford: get_status, or GET /api/summary for level and streak.
  • Recent trend: get_history, or GET /api/state?history=1 (last 14 days).

Taking actions

  • Mark a task done with complete_task (task title or id). Undo with undo_task. Add a one-off task with add_side_quest.
  • Confirm with Lucas before changing anything, and report the XP change from the response.
  • Parent actions (editing tasks, rewards, approving reward claims) are not available here; they need the parent PIN in the app.
